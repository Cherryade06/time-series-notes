Fundamental Concepts

Additive model

\[ X_t = m_t + s_t + Y_t \]

What this means: A time series is like a recipe with three ingredients — a smooth long‑term movement (trend \(m_t\)), a repeating pattern (seasonality \(s_t\)), and random leftover noise (\(Y_t\)). We want to separate these three parts so we can study each one.

Multiplicative model and log transformation

\[ X_t = m_t\,s_t\,Y_t \;\Longrightarrow\; \log X_t = \log m_t + \log s_t + \log Y_t \]

What this means: Sometimes the ups and downs grow with the level of the series (like stock returns). Taking logs turns multiplication into addition, which is easier to handle with the additive model.

Heteroscedasticity vs homoscedasticity

Heteroscedasticity means the variability of the series changes over time (e.g., gets bigger). Homoscedasticity means it stays constant. Many models assume constant variance, so we often need to fix this.

Chapter 1 – Estimating the Trend

Least squares for linear trend

\[ \hat\beta_1 = \frac{\sum (t_i-\bar t)(x_i-\bar x)}{\sum (t_i-\bar t)^2},\qquad \hat\beta_0 = \bar x - \hat\beta_1\bar t \]

What this means: The slope \(\hat\beta_1\) is the “rise over run” — how much \(x\) changes per one unit of time on average. The intercept \(\hat\beta_0\) is the value of \(x\) at time 0. The line always passes through the “centre” of the data \((\bar t, \bar x)\).

Polynomial regression (matrix form)

\[ \mathbf{X} = \mathbf{W}\boldsymbol\beta + \boldsymbol\varepsilon,\qquad \hat{\boldsymbol\beta} = (\mathbf{W}^T\mathbf{W})^{-1}\mathbf{W}^T\mathbf{X} \]

What this means: Instead of a straight line, we fit a curve (quadratic, cubic, …). We stack all the data into matrices and solve for the best coefficients all at once — this is the same idea as linear regression but with extra columns for \(t^2, t^3,\dots\)

Chapter 2 – Moving Average Smoothing and Filters

Odd moving average

\[ \hat m_t = \frac{1}{2q+1}\sum_{j=-q}^{q} x_{t-j} \]

What this means: Replace each data point with the average of itself and its \(q\) left and \(q\) right neighbours. This smooths out random bumps and reveals the underlying trend.

Even moving average (half‑weighted ends)

\[ \hat m_t = \frac{1}{2q}\Bigl(\tfrac12 x_{t-q} + x_{t-q+1} + \dots + x_{t+q-1} + \tfrac12 x_{t+q}\Bigr) \]

What this means: When we need an even number of points, we give the two farthest ones only half weight so the average is still centred symmetrically.

Linear filter (convolution)

\[ w_t = \sum_{j=-q}^{q} a_j x_{t-j} \]

What this means: A weighted moving average where different neighbours can have different importance. Choosing the weights cleverly lets us keep certain patterns (e.g. linear trend) undistorted while removing noise.

Filter design conditions

  • Linear trend passes through undistorted if: \(\sum a_j = 1\) and \(\sum j a_j = 0\).
  • Quadratic: add \(\sum j^2 a_j = 0\).
  • Cubic: add \(\sum j^3 a_j = 0\).
What this means: These conditions guarantee that if the true trend is a straight line (or a parabola, etc.), smoothing won’t bend or shift it.

Chapter 3 – Exponential Smoothing and Differencing

Exponential smoothing

\[ \hat m_t = \alpha x_t + (1-\alpha)\hat m_{t-1} \]

What this means: Today’s trend estimate is a blend of today’s actual value and yesterday’s trend estimate. The weight \(\alpha\) (between 0 and 1) controls how quickly we react to new data. Higher \(\alpha\) = more responsive to recent changes. This is a “one‑sided” method — it only uses past data, so it can be used for forecasting.

Span

\[ N = \frac{1-\alpha}{\alpha} \]

What this means: If \(\alpha=0.1\), \(N=9\) — the average “age” of the data influencing the estimate is about 9 time points.

Holt method (trend‑corrected exponential smoothing)

  • Level: \(m_t = \alpha x_t + (1-\alpha)(m_{t-1}+b_{t-1})\)
  • Trend: \(b_t = \beta (m_t - m_{t-1}) + (1-\beta) b_{t-1}\)
  • Forecast: \(\hat x_{t+h} = m_t + h\,b_t\)
What this means: When the series has a steady upward or downward slope, plain exponential smoothing always lags behind. The Holt method adds a separate trend line that learns how fast the series is changing, and the forecast extends that trend forward.

Trend differencing

\[ \nabla x_t = x_t - x_{t-1} \]

What this means: Instead of modelling and subtracting the trend, we simply look at the changes from one time point to the next. If the trend was linear, these changes are now roughly constant (no trend left). Repeating differencing \(d\) times removes a polynomial trend of degree \(d\).

Chapter 4 – Seasonality

Seasonal period

\(s_{t+S} = s_t\), e.g. \(S=12\) for monthly data with yearly pattern.

What this means: The seasonal component repeats exactly every \(S\) time points (every January looks the same, every February looks the same, etc.).

Brockwell & Davies algorithm outline

  1. Estimate trend with an \(S\)-point moving average (so seasonal bumps are averaged out).
  2. Subtract trend → get “de‑trended” series.
  3. Average the de‑trended values for each season (e.g. all Januaries) → raw seasonal indices.
  4. Centre the indices so their mean is zero.
  5. Subtract seasonality → “deseasonalised” series; what’s left is noise.
What this means: A systematic, step‑by‑step recipe to dismantle a time series into its three building blocks. R’s decompose() does exactly this.

Holt‑Winters (with seasonality)

  • Level: \(m_t = \alpha (x_t - s_{t-S}) + (1-\alpha)(m_{t-1}+b_{t-1})\)
  • Trend: \(b_t = \beta (m_t - m_{t-1}) + (1-\beta) b_{t-1}\)
  • Seasonal: \(s_t = \gamma (x_t - m_{t-1} - b_{t-1}) + (1-\gamma) s_{t-S}\)
  • Forecast: \(\hat x_{t+h} = m_t + h b_t + s_{t - S + 1 + (h-1)\bmod S}\)
What this means: Holt‑Winters extends the Holt method by adding a seasonal component that also learns and updates its estimate of the yearly pattern. The three weights \(\alpha,\beta,\gamma\) control how quickly the level, trend, and seasonality adapt.

Seasonal differencing

\[ \nabla_S x_t = x_t - x_{t-S} \]

What this means: Instead of modelling seasonality, we just look at the difference between this month’s value and the same month one year ago. This kills the seasonal pattern immediately. It commutes with ordinary differencing, so we can do both in any order.

Harmonic decomposition

\[ s_t = a_0 + \sum_{j=1}^k \Bigl( a_j\cos\frac{2\pi j t}{S} + b_j\sin\frac{2\pi j t}{S} \Bigr) \]

What this means: We can write any seasonal pattern as a sum of sine and cosine waves of different frequencies. This is useful when there are multiple overlapping cycles (e.g., weekly + yearly patterns in electricity demand).

Chapter 5 – Residual Analysis and Probability Revision

Box‑Cox transformation

\[ x_t^{(\lambda)} = \begin{cases} \dfrac{x_t^\lambda -1}{\lambda}, & \lambda \neq 0,\\[4pt] \log x_t, & \lambda = 0. \end{cases} \]

What this means: A family of mathematical transformations that can make a series more homoscedastic. We let the data choose the best \(\lambda\) (often near 0, i.e. a log). A log transform is the most common fix when variance grows with the level.

Covariance and correlation

\[ \operatorname{Cov}(X,Y)=\mathbb{E}[(X-\mathbb{E}X)(Y-\mathbb{E}Y)],\qquad \rho_{XY}= \frac{\operatorname{Cov}(X,Y)}{\sqrt{\operatorname{Var}(X)\operatorname{Var}(Y)}} \]

What this means: Covariance measures whether two variables move together (positive = together, negative = opposite). Correlation is a standardised version between \(-1\) and \(1\) that ignores the units.

Partial correlation \(\rho_{XY\cdot Z}\)

What this means: The correlation left between \(X\) and \(Y\) after removing the influence of a third variable \(Z\). For example, height and reading ability may be correlated only because they both depend on age; partial correlation with age held constant would likely be near zero.

Weak stationarity

  1. \(\mathbb{E}[X_t] = \mu\) constant for all \(t\)
  2. \(\operatorname{Cov}(X_{t+h}, X_t) = \gamma(h)\) depends only on lag \(h\), not on \(t\)
What this means: The series has no trend (mean doesn’t wander), and the way values relate to each other doesn’t change over time. This is what we expect the residual \(Y_t\) to look like after we remove trend and seasonality.

Chapter 6 – Stationary Processes

White noise \(Z_t \sim \text{i.i.d. } N(0,\sigma^2)\)

ACF: \(\rho(0)=1,\ \rho(h)=0\) for \(h\neq0\)

What this means: The simplest stationary process — each observation is a fresh random draw, completely unrelated to the past. The ACF is a single spike at lag 0. If our residuals look like white noise, we know we’ve extracted all the predictable structure.

Sample ACF confidence bounds

Approximately \(\pm 1.96/\sqrt{n}\) for white noise.

What this means: Even for pure white noise, sample autocorrelations won’t be exactly zero — they vary randomly. The blue dashed lines on an ACF plot show the range where 95% of these random estimates should fall. Bars sticking out suggest real autocorrelation.

MA(1) process \(X_t = Z_t + \theta Z_{t-1}\)

\(\gamma(0)=\sigma^2(1+\theta^2),\ \gamma(\pm1)=\theta\sigma^2,\ \text{zero thereafter}\)

What this means: Today’s value is today’s shock plus a fraction of yesterday’s shock. The ACF has exactly one non‑zero spike at lag 1 (besides lag 0). This is a “short memory” process — the effect of a shock lasts exactly one time step.

MA(q) general formula

\[ \gamma(h) = \sigma^2\sum_{i=0}^{q-|h|} \theta_i \theta_{i+|h|}\quad (\theta_0=1) \]

What this means: The ACF of an MA(q) is exactly zero for lags bigger than \(q\). This gives us a clear diagnostic: if the sample ACF cuts off abruptly after lag \(q\), an MA(q) is a good candidate model.

Chapter 7 & 8 – AR(1), AR(p), Causality, and Invertibility

AR(1) causal (\(|\phi|<1\)) ACF

\[ \gamma(h)=\frac{\phi^{|h|}\sigma^2}{1-\phi^2},\qquad \rho(h) = \phi^{|h|} \]

What this means: Today’s value depends on yesterday’s value plus a new shock. The ACF decays geometrically (like a dying echo). The process is “causal” because it is built only from past shocks.

Causality condition

  • AR(1): \(|\phi|<1\)
  • AR(p): all roots of \(\phi(z)=1-\phi_1 z-\dots-\phi_p z^p\) lie outside the unit circle.
What this means: For an AR process to make sense (and not depend on the future), its characteristic polynomial must have roots larger than 1 in absolute value. This guarantees the process can be written as an infinite sum of past white noise terms.

Yule–Walker equations

\[ \gamma(0) = \phi_1\gamma(1) + \dots + \phi_p\gamma(p) + \sigma^2 \]

\[ \gamma(h) = \phi_1\gamma(h-1) + \dots + \phi_p\gamma(h-p),\quad h>0 \]

What this means: There is a precise mathematical relationship linking the AR coefficients, the noise variance, and the autocovariances. We can solve these equations to find the ACF pattern for any AR(p). The ACF tails off (decays gradually), which distinguishes AR from MA.

MA(1) invertibility \(|\theta|<1\)

What this means: If \(|\theta|<1\), we can rewrite the MA(1) as an infinite AR representation — i.e., we can reconstruct the white noise shocks from current and past values of the series. Non‑invertible MA processes have identical ACFs to invertible ones, so we always choose the invertible version for practical modelling.

Chapter 9 – Partial Autocorrelation (PACF)

Definition

Partial correlation between \(X_t\) and \(X_{t-h}\) after removing the linear effect of \(X_{t-1},\dots,X_{t-h+1}\).

What this means: While the ordinary ACF measures the total correlation at lag \(h\) (which can be “inherited” from intermediate lags), the PACF measures the direct connection. For example, if \(X_t\) only depends on \(X_{t-1}\), the ACF at lag 2 might be non‑zero (because \(X_{t-1}\) is linked to \(X_{t-2}\)), but the PACF at lag 2 will be zero.

Identification table

ModelACFPACF
MA(\(q\))cuts off after lag \(q\)tails off gradually

What this means: Look at the sample ACF and PACF plots from your data.
- If ACF drops to zero suddenly after a few lags, and PACF decays → MA.
- If PACF drops to zero suddenly, and ACF decays → AR.
This table is the key to choosing the right model order.

Chapter 10 – Fitting and Forecasting

Fitting in R

  • arima(x, order=c(0,0,q)) fits MA(q)
  • arima(x, order=c(p,0,0)) fits AR(p)
What this means: R finds the coefficients that make the model best fit the data (by maximum likelihood). You specify the \(p,d,q\) order — here \(d=0\) because we assume the data is already stationary.

AR(1) forecast one step ahead

\[ \hat X_{t+1} = \phi X_t \]

What this means: Since the noise has mean zero, our best guess for tomorrow is just today’s value multiplied by \(\phi\). If \(\phi=0.8\), we expect tomorrow to be 80% of today’s deviation from the mean (plus a fresh random shock that is zero on average).

MA(1) forecast one step ahead

\[ \hat X_{t+1} = \theta Z_t \]

What this means: For MA models, the forecast is based on the estimated past shock \(Z_t\). Because the process is invertible, we can work out what shock must have occurred today from the observed data. Future shocks are unknown and set to zero.

Autoregressive forecasting (general)

\[ \hat X_{t+h} = \phi_1 \hat X_{t+h-1} + \dots + \phi_p \hat X_{t+h-p} \]

What this means: For AR models, we just roll the equation forward. For lags beyond the first, we plug in our own previous forecasts. This makes AR forecasts very straightforward.
